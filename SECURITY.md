# Security Policy

## Supported Versions

We actively provide security patches and updates for the following versions of Atlas:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Atlas, please help us protect our users by following responsible disclosure practices:

1. **Do NOT open a public GitHub issue** to report security vulnerabilities.
2. Please send a private email to the maintainers or report via GitHub Private Vulnerability Reporting if enabled.
3. Include detailed steps to reproduce the vulnerability, including payload examples, screenshots, or code snippets.
4. We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a timeline for verification and remediation.

Thank you for keeping Atlas and its community secure!
